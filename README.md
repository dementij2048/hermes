hermes
=====
Гермес является альтернативой традиционным электронным журналам, с открытым исходным кодом и легко расшираемым кодом.

### Как его запустить?
Рекомендованным способом запуска является использование docker/podman
#### 1. Скомпилировать образ
```
docker build -t app ./
```
#### 2. Запустить его
Примечание: 3257:3257 это порт в контейнере и порт на сервере соответсвенно, по умолчанию программа использует порт 3257, поэтому для его смены надо сменить его в самом коде
```
docker run -p 3257:3257 app
```
